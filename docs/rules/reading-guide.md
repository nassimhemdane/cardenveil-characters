# Sources et divergences

## Deux niveaux de documentation

Les documents sources sont des transcriptions des huit PDF du dossier RulesCardenveil. Le texte
est conservé par page, sans arbitrage ni réécriture des règles. Les illustrations ne sont pas
incluses ; les tableaux extraits peuvent perdre leur disposition originale.

Les fiches de référence proviennent des Markdown de docs/rules. Elles ont été structurées pour le
core et la recherche documentaire ; elles ne constituent pas un manuel complet et certaines
citent un corpus consolidé plus ancien. Leur mention canonical est un statut dans ce corpus,
pas la garantie qu'elles correspondent à la dernière version des PDF.

## Points de vie

Le PDF Personnage, page 1, indique **60 + (5 × Force)**. La synthèse du core conserve une autre
formule, **35 + 2 × Force**, et la marque unresolved en raison d'une divergence avec une fiche.
Ces valeurs ne sont pas fusionnées : faites confirmer la version applicable par le MJ.

## Main de cartes

La référence rapide, page 1, indique **3 cartes** en main. Le PDF Totem, Capacités & Cartes,
page 1, indique **2 cartes** avant de passer le tour et repiocher. La bibliothèque conserve
les deux textes sans choisir arbitrairement lequel remplace l'autre.

## Capacités connues

Le PDF Totem, Capacités & Cartes, page 1, indique Esprit divisé par deux, arrondi à l'inférieur.
La synthèse du core signale des variantes d'arrondi dans ses sources. Consultez le document
retenu pour votre campagne.

## Lecture et maintenance

La navigation distingue les documents sources des fiches de référence. Les liens Page N
permettent de citer précisément une transcription. La recherche couvre ces deux ensembles.
Cette liste de divergences est indicative, pas un audit exhaustif des règles.

Les archives de personnages ne sont jamais recalculées ou modifiées par cette documentation.
